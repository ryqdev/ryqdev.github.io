# RSS subscriptions

Every HTML page has an RSS button in the top navigation. Opening it reveals
English and Chinese subscription links; on mobile, the button uses an RSS icon.
The language-specific Atom feeds contain the latest 20 published articles in the
chosen language, including full HTML content, publication/update dates, and tags:

- English: `/feed/en.xml`
- Chinese: `/feed/zh.xml`

Feed autodiscovery lists the current language first. Existing subscriptions to
the combined `/feed.xml` generated by jekyll-feed continue to work.

Both feeds are static Liquid layouts supported by GitHub Pages, with absolute
entry URLs, stable URL-based IDs, XML escaping, and an XML base for body links.
Readers can open either subscription link and copy its URL into an RSS reader. No
mailing-list service, account, or browser JavaScript is required.
