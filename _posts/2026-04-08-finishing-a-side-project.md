*A sample article.*

Starting leaves every possibility open. Finishing means choosing which of those
possibilities belongs in this version and which can wait.

## Define a small complete version

Write down what someone should be able to do from beginning to end. Use that
journey to decide which features belong in the first version.

> A clear stopping point is part of the design.

## Save the next idea for later

An idea does not have to be discarded just because it is not being built today.
Keep a short list outside the current task, then return to the version in front
of you.

Finishing can be a quiet decision: this does the thing it set out to do, and it
is ready for someone else to try.
