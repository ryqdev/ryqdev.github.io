A good tool earns its place through repeated use. It does not need to solve
every problem; it needs to make one familiar task a little easier.

## Keep the useful defaults

Start with a small set of choices: where notes live, how projects are named,
and what happens when a task is finished. Add another convention only when a
recurring inconvenience makes the need clear.

- Keep a single place for unfinished thoughts.
- Give each project an obvious starting point.
- Make the next action easy to find.

## Build around the habit

The most elaborate setup is not always the one that lasts. A plain text file
that gets opened every day can be more useful than a perfect system that is
difficult to maintain.
